QUICK START (5 MINUTES):

1. Add 8 GitHub Secrets:
   GitHub → Repo Settings → Secrets and variables → Actions
   Add: DOCKER_USERNAME, DOCKER_PASSWORD, VITE_SUPABASE_*, VITE_FIREBASE_*

2. Push workflow:
   git add .github/workflows/docker-build-push.yml
   git commit -m "Add CI/CD"
   git push origin main

3. Watch build:
   GitHub → Actions tab → "Build & Push Docker Image" workflow

DONE! Every commit now auto-builds & pushes to Docker Hub.

KUBERNETES DEPLOYMENT (Optional):

With cluster:
  bash scripts/k8s-deploy.sh
  
  OR manually:
  kubectl apply -f k8s/deployment.yaml
  kubectl apply -f k8s/ingress.yaml

Without cluster:
  Skip Kubernetes and use Docker Compose locally:
  docker compose up

HELP:

- Kubernetes failing? → kubectl logs -f deployment/hteim-school-of-ministry -n hteim-school-of-ministry
- Health check fail? → kubectl port-forward svc/hteim-service 3000:80; curl localhost:3000/api/health
